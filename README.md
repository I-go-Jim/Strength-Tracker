# Sean's Strength Tracker V9

## V9 changes
- Added an editable Exercises tab
- Workouts are now more universal and based on a workout library
- Exercise defaults now use a single Reps field instead of min/max
- Workout buttons show the training day of the week
- Workout buttons are more compact
- Newly added exercises auto-scroll into view
- Existing workout history and timers are preserved
- Built as a static GitHub Pages app with localStorage persistence
